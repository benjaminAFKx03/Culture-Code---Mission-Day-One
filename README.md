# Culture Code – Mission Day One

A browser-based 3D exit game on intercultural psychology, developed for the module Intercultural Psychology (eufom, winter semester 2026/27).

Teams of three to five students take on the role of the Global Task Force at HORIZON Group on Day One of a cross-border merger. In 15 minutes they diagnose the corporate culture, find out where the employees stand and present a consistent plan in the Boardroom.

## Play

Open `index.html` in any current browser. The game is a single self-contained file and needs no installation and no internet connection.

Online version: see the GitHub Pages link in the About section of this repository.

## Tasks

1. Below the Surface: Iceberg Model of Culture (Schein, 1985)
2. Onboarding Radar: acculturation strategies (Berry, 2005)
3. Growth Ladder: Developmental Model of Intercultural Sensitivity (Bennett, 1986)
4. Field Notes: Hall (1976), Hall and Hall (1990), Hofstede (1991), Trompenaars (1993), Gelfand et al. (2011)
5. Boardroom Showdown: intercultural synergy (Adler, 1986)

## Controls

Arrow keys to walk and turn, spacebar to talk and interact. On phones and tablets, a joystick and taps.
